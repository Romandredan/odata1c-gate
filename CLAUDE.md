# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Основной контекст — в AGENTS.md

@AGENTS.md

`AGENTS.md` — единственный источник по проекту: обзор, структура репозитория, целевая
архитектура, стек, команды CLI, стратегия тестирования, инварианты, соглашения по документации
и безопасности. Этот файл его не дублирует, а добавляет только то, что касается работы
Claude Code в данном репозитории. Когда появятся код и манифесты сборки, команды сборки, линта
и тестов дописываются в `AGENTS.md`; `CLAUDE.md` остаётся указателем.

## Это не 1С-конфигурация

Репозиторий проектирует Python-сервис, который *обращается* к 1С по OData. Исходников 1С здесь
нет: ни `src/cf`, ни `src/cfe`, ни `.v8-project.json`. Отсюда:

- MCP `code-index`, страж навигации, агенты `bsl-*` и скиллы `epf-*` / `cfe-*` / `meta-*` /
  `form-*` / `kd3-*` к этому репозиторию не применяются — не пытайтесь подключать индекс кода
  и не ищите здесь конфигурацию 1С;
- поиск и чтение файлов — обычные `Grep` / `Read`, ограничений нет;
- процессный слой — generic superpowers (`brainstorming`, `systematic-debugging`,
  `writing-plans`), а не доменные `brainstorm-1c` / `debug-1c`.

Не путайте с MCP-сервером `1c-odata`, который уже настроен в других проектах для чтения боевых
баз (агент `odata-investigator`, скилл `mcp-1c-odata-setup`). Здесь проектируется **другой**
продукт — `odata1c-gate`; настройка того сервера в задачи этого репозитория не входит.

## Порядок чтения документов

`SPEC.md` — 69 КБ и 16 разделов, целиком читать не нужно. Обычная последовательность:

1. `CONTEXT.md` — термины и запрещённые синонимы (`_Avoid_`); словарь проекта задан здесь;
2. `AGENTS.md` — общая картина;
3. нужный раздел `SPEC.md` — найти через `grep -n '^## ' SPEC.md` и читать точечно по смещению;
4. `docs/adr/` — только когда затрагивается само решение; статус смотреть во frontmatter
   (`accepted` / `superseded` / `amended`).

## Что менять синхронно

Изменение архитектуры затрагивает несколько документов сразу: новое или пересмотренное решение
— ADR в `docs/adr/`, следом соответствующий раздел `SPEC.md`, новый термин — `CONTEXT.md`,
и `AGENTS.md`, если задет один из описанных в нём разделов. Расхождение между этими файлами —
дефект, а не мелочь.
