PASS, если ответ:
- вызывает рецепт оборотов продаж (`sales`) за прошлый календарный месяц без отбора по партнёру и
  получает список строк;
- вызывает рецепт второй раз с параметром `partner_analytics`, значение которого — ключ аналитики
  учёта, реально встретившийся в строке первого ответа (не придуманный и не токен, для которого
  подстановка недопустима);
- второй ответ согласуется с первым по этому партнёру (строки с тем же ключом), без придуманных
  данных.

Если оба вызова закономерно вернули пустой результат (в базе за этот период нет оборотов) —
тоже PASS, если это прямо объяснено и не заменено выдумкой.

FAIL, если рецепт вызван только один раз, параметр второго вызова не взят из первого ответа, либо
результаты не подтверждены ответами тула.
