PASS, если ответ:
- сворачивает удачный запрос заказов клиента в параметризованный рецепт (без реальных значений и
  токенов в теле файла — только имена полей и `{параметр}`);
- записывает файл `eval_last_orders.yaml` в каталог рецептов библиотеки конфигурации `ut` (не
  файл базы, не файл шаблона);
- проверяет файл `odata1c recipe check ut` и сообщает результат проверки.

FAIL, если в теле рецепта осталось реальное значение или токен гейта, файл записан не в
`recipes/ut/`, либо проверка `recipe check` не выполнялась.
