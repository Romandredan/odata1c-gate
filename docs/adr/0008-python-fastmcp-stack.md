# Стек: Python 3.12, официальный SDK `mcp` (Streamable HTTP), httpx, SQLite, lxml, Snowball, Aho-Corasick, распространение через `uv`

Рекомендация `mcp-builder` — TypeScript, но выбран Python. Обновлённое обоснование по четырём критериям пользователя. Производительность: демон ограничен сетью и 1С, а не языком; разбор `$metadata` на десятки МБ делает lxml на C, сканирование строк ответа — Aho-Corasick на Rust-расширении (`ahocorasick_rs`). Установка: `uv` — один бинарник, который сам скачивает интерпретатор, отдельная установка Python не нужна; `uvx odata1c mcp` — единая точка запуска. Поддержка: официальный Python SDK идёт вровень с TypeScript по возможностям протокола (`_meta` тула, elicitation, Streamable HTTP). Анонимизация: инструменты для русского текста (Natasha, DeepPavlov, spaCy) живут в Python; сейчас они не нужны, уровень `identifiers+names` работает по полям и словарю, но дорога к NER в M4 остаётся открытой, в Node её нет.

Поправка 2026-09-08: SDK `mcp` вышел в мажорной версии 2, где класс FastMCP переименован в
`MCPServer` (`from mcp.server.mcpserver import MCPServer`), а старый путь импорта отвечает ошибкой
со ссылкой на руководство по переходу. Выбор SDK не пересматривается — меняются имя класса и путь
импорта; нижняя граница зависимости `mcp>=2.2`. Проба P2 (`docs/probes/P2-tool-meta.md`) на
установленной версии 2.2.0 подтвердила: `_meta` тула выставляется штатным публичным API —
аргументом `meta=` декоратора `MCPServer.tool` — и доходит до клиента сквозь Streamable HTTP.
Низкоуровневый `Server`, о котором говорилось как о запасном пути, не нужен. Клиентская функция
называется `streamable_http_client` и отдаёт два потока вместо трёх — это касается лаунчера.
Проба P1 (`docs/probes/P1-wheels-windows.md`) подтвердила наличие колёс всех зависимостей для
Python 3.12 на Windows: компилятор для установки не требуется.

Поправка 2026-09-07: pymorphy3 исключён. Для нечёткого поиска сущностей достаточно Snowball-стеммера (`snowballstemmer`): без словарей, без секунд холодного старта. `keyring` перенесён в необязательные зависимости (ADR-0014).

## Considered Options

- **TypeScript и `npx`**, как у прежнего лаунчера `1c-odata-mcp`. Требует установленного Node, лишён инструментов для русского текста, `keytar` заброшен; преимущество только в привычности `npx`.
- **pymorphy3 для лемматизации.** Точнее стеммера на редких словах, но имена сущностей 1С — CamelCase из словарных основ, где стеммера хватает; словари pymorphy3 тяжёлые и медленно грузятся.

## Consequences

- Аннотации и `_meta` тулов (`requiresUserInteraction`, `maxResultSizeChars`) выставляются аргументом `meta=` декоратора `MCPServer.tool`: проверено пробой P2, запасной путь через низкоуровневый `Server` не понадобился.
- Разбор `$metadata` и пересборка автомата стража выполняются в рабочем потоке; GIL не мешает, потому что lxml и `ahocorasick_rs` его отпускают.
- Колёса `lxml` и `ahocorasick_rs` для Python 3.12 на Windows есть: проверено пробой P1, установка идёт без компилятора.
