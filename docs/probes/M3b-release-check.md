## Что не проверялось и почему

- **Evals плагина** — навыки, агент и хук в выпуске не менялись, а прогон стоит около 8 USD и
  проверяет поведение модели, а не гейт; изменения гейта проверены прямыми пробами на живой базе.
- **Вопросы через `claude -p` с плагином из маркетплейса** — плагин в профиле владельца закреплён
  на `0.1.0` и обновляется только с его согласия; после обновления достаточно одного вопроса
  чтения.

## За владельцем

1. Обновить плагин: `claude plugin marketplace update odata1c-gate`, затем
   `claude plugin update odata1c@odata1c-gate`; командную строку — `uv tool upgrade odata1c-gate`.
2. Перезапустить демон на новом коде: `odata1c daemon stop`, затем `/mcp` → переподключить шлюз.
