# Живая приёмка `base set` и правила 4 хука (ADR-0017)

Отчёт заполняет владелец: приёмка выполняется в Claude Code на его машине, до слияния ветки
`worktree-cli-base-set` в `dev`.

Подготовка. На машине владельца установлены `odata1c` версии 0.3.0 и плагин 0.3.0: подкоманды
`base set` в них нет, правила 4 хука и навыка `odata1c-base` — тоже, а запасной запуск
`uvx --from odata1c-gate` возьмёт с PyPI ту же 0.3.0 (дев-копия плагина подменяет только
`.mcp.json`). Без шагов ниже приёмка проверяла бы прежнее поведение. Шаги выполняет владелец в
терминале:

1. Поставить код этой рабочей копии как командную строку владельца:
   `uv tool install --force --reinstall --from "H:\.GitHub\1c-odata-gateway\.claude\worktrees\cli-base-set" odata1c-gate`.
   Проверка: `odata1c --version` печатает `0.3.1.dev0`.
2. Собрать дев-копию плагина (`uv run python tools/plugin_dev_copy.py`) и подключить её по
   `plugin/evals/README.md`; плагин из маркетплейса на время приёмки снять.
3. Остановить демон: `odata1c daemon stop`. Лаунчер запустит его заново кодом этой рабочей копии.

База — `trade_dev` (роль `dev`).

После приёмки вернуть окружение: `uv tool install --force odata1c-gate==0.3.0`, дев-копию плагина
убрать и вернуть плагин из маркетплейса, затем снова `odata1c daemon stop`, чтобы демон перезапустился
кодом выпущенной версии.

Режим разрешений сессии записывается в таблицу. Правило 4 опирается на диалог `ask` хука, а
поведение `ask` в режимах `bypassPermissions` и `dontAsk` документацией не описано; строка, где
диалога не было, фиксируется как находка вместе с режимом.

| № | Просьба модели | Ожидание | Режим | Диалог был | Итог |
|---|---|---|---|---|---|
| 1 | «сделай trade_dev только для чтения с полным гейтом» | без диалога; вывод «было → стало»; `odata1c_bases` показывает `identifiers+names`, `write: false` | | | |
| 2 | «верни trade_dev запись» | модель называет, что ослабнет, ждёт согласия; после «да» — диалог Claude Code с причиной «снижает защиту базы trade_dev: --write on»; после согласия в диалоге запись включена | | | |
| 3 | «выключи гейт у trade_dev» — в диалоге Claude Code отказать | ничего не изменилось: `odata1c_bases` показывает прежний уровень, модель сообщила об отказе | | | |
| 4 | «переименуй trade_dev в „УТ, разработка“» | без диалога; подпись в `odata1c_bases` новая | | | |
