# Ruling 106: название только отдельным словом — приёмка на живой базе

Дата: 2026-09-24. База: `trade_dev` (УТ), уровень гейта `identifiers+names`. Повод — issue №2:
короткое название организации из словаря («Мост», «РУДН» — по 4 символа) заменялось токеном
внутри других слов, портило данные 1С («себестои[[org:N]]и») и имена метаданных в ответах
`odata1c_recipe` и `odata1c_find_entity`.

Скрипт: `tools/probes/word_boundary_live_check.py`. Работает во временном домашнем каталоге (порт
7197) с пустым словарём; рабочий дом владельца и его демон не трогаются. Словарь наполняется
чтением `Description` справочников `Контрагенты` (1482), `Партнеры` (2758), `Организации` (3),
`ФизическиеЛица` (166), `КонтактныеЛицаПартнеров` (1977). Затем снимаются перечень рецептов,
восемь запросов `find_entity` и свободный текст: `Description` номенклатуры (3000), `Комментарий`
реализаций и заказов клиентов (по 3000), `Комментарий` и `НазначениеПлатежа` поступлений (1197) и
списаний (1532) безналичных. Печатаются только счётчики и форма окружения токена (буква → a).

«До» — код ветки `dev` (`ce9838b`), подставленный ключом `--src`; «после» — код правки `dc8ac38`.
Повторные прогоны на `ee920cc` (исправление находок атакующего ревью: экранирование JSON,
невидимые разделители, буквы Lm) и на итоговом `3bee7f8` (решения владельца: склейки внутри
слова, путь Windows не портится, смена письменности — граница, буквы-двойники и ударение —
продолжение слова) дали те же числа: 0 внутри слова, 334 отдельным словом, 0 ответов с
`guard_replaced` во всех трёх разделах.

| Раздел | Токенов внутри слова, до → после | Токенов отдельным словом, до → после | Ответов с `guard_replaced`, до → после |
|---|---|---|---|
| Перечень рецептов | 2 → 0 | 0 → 0 | 1 → 0 |
| `find_entity`, 8 запросов | 74 → 0 | 0 → 0 | 7 → 0 |
| Свободный текст | 685 → 0 | 334 → 334 | 3 → 0 |

Выводы:

1. Порча внутри слова устранена полностью: 761 место до правки, ни одного после. Самые частые
   формы до правки — `aaaaTaaaa` в именах метаданных (45 из 74) и `aaa Taaaa` в свободном тексте
   (400 из 685): токен в начале или середине обычного слова.
2. Названия, стоящие отдельным словом, закрываются как прежде: 334 токена до и после.
3. Среди 685 бывших замен внутри слова могли быть склонённые формы названий («от Вектора»); они
   теперь открыты — цена, принятая владельцем (SPEC §6.10). Отличить их от порчи обычных слов по
   счётчикам без значений нельзя.

Сущности `Document_ПоступлениеТоваровУслуг` в этой базе нет (`entity_unknown`), её поле пропущено.
