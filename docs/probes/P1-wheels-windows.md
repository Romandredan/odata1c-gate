# P1 — колёса зависимостей под Windows и Python 3.12

Дата: 2026-09-08 · план: [M0](../plans/2026-09-07-m0-probes.md), задача 1 · статус: **закрыта**

## Вопрос

SPEC §15, пункт 5: «`ahocorasick_rs` и `lxml` на Windows под `uv`: наличие колёс для Python 3.12».
Если хотя бы одна зависимость собирается из исходников, установка через `uvx` на чистой машине
потребует компилятор, и обещание SPEC §11.4 «установка без ручных шагов» не выполняется.

## Как проверял

`tools/probes/p1_wheels.ps1` + `tools/probes/p1_imports.py`: чистое окружение на Python 3.12,
установка девяти зависимостей SPEC §11.1 с флагом `--only-binary=:all:` (запрещает сборку из
исходников), затем импорт каждой с минимальной проверкой работы.

Окружение: Windows NT 10.0.26200.0, `uv 0.9.24`, CPython 3.12.12 AMD64.

Команда: `powershell -ExecutionPolicy Bypass -File tools/probes/p1_wheels.ps1`

## Что получилось

Установка прошла без единой сборки из исходников: 42 пакета (9 прямых зависимостей и их
зависимости), «Resolved 42 packages in 907ms, Installed 42 packages in 272ms».

Версии прямых зависимостей:

| Пакет | Версия |
|---|---|
| `mcp` | **2.2.0** |
| `httpx` | 0.28.1 |
| `pydantic` | 2.13.5 |
| `pyyaml` | 6.0.3 |
| `lxml` | 6.1.3 |
| `snowballstemmer` | 3.1.1 |
| `ahocorasick-rs` | 1.0.3 |
| `uvicorn` | 0.52.4 |
| `keyring` | 25.7.0 |

Проверка работоспособности:

```text
python 3.12.12 AMD64
lxml 6.1.3
ahocorasick_rs: ['ромашка']          # кириллица находится
snowball: контрагент                  # русский стеммер работает
mcp версия не экспортирована
httpx 0.28.1 | pydantic 2.13.5 | uvicorn 0.52.4
yaml 6.0.3
```

## Ответ

**Да.** Все девять зависимостей SPEC §11.1 ставятся под Windows и Python 3.12 готовыми колёсами,
компилятор не нужен. Состав зависимостей подтверждён, замены не требуются.

## Следствия

1. **Пакет `mcp` вышел в версии 2.2.0, а не 1.x.** Черновик `pyproject.toml` в плане M1a (задача 1)
   содержит нижнюю границу `mcp>=1.9` — заменить на `mcp>=2.2`. Мажорная версия SDK делает пробу P2
   (`_meta` тула через FastMCP) обязательной к исполнению до плана M1d: API мог измениться
   относительно того, что описано в SPEC §15 и §2.2. Заодно `mcp` 2.2.0 тянет собственные
   `mcp-types`, `httpx2` и `httpcore2` — в прямые зависимости их вписывать не нужно.
2. **`snowballstemmer` вышел в версии 3.1.1**, нижнюю границу `>=2.2` в манифесте можно оставить:
   ограничение выполняется.
3. **Скрипты PowerShell с кириллицей сохранять в UTF-8 с BOM.** Windows PowerShell 5.1 без BOM
   читает файл как ANSI: первый же комментарий с кириллицей ломает разбор строковых литералов
   (`TerminatorExpectedAtEndOfString`). Первый прогон пробы упал именно на этом. Правило относится
   ко всем `.ps1` в `tools/`; на файлы `.py` не распространяется — Python читает UTF-8 сам.

Изменений в спецификации не требуется: SPEC §11.1 перечисляет пакеты без версий, а нижние границы
живут в `pyproject.toml`, которого ещё нет. Правка нижней границы `mcp` вносится при исполнении
задачи 1 плана M1a.
