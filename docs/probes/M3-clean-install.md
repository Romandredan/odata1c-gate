## Проверка 3. Evals на установленном плагине — пройдена

`claude plugin eval odata1c@odata1c-gate --mocks off --runs 1 --ablation none --no-publish
--tag read --tag recipe …` (команда — `plugin/evals/README.md`), данные — дом владельца, демон
владельца на 7171 (код утреннего запуска, чтение). Итог первого прогона — 12 дел из 13, общий
счёт 0,985, 735 с, 8,56 USD. Не прошло дело `11-recipe-date` у судьи `llm` (три голоса FAIL):
рецепт остатков был выполнен верно (судья `tool` пройден, реквизитов в ответе нет), но модель
вместо таблицы дала частичный разбор первых 200 строк из ~25 тысяч и предложила сузить выборку.
Повторный прогон только этого дела — пройдено, 5 судей из 5, 1,97 USD. В прогоне задачи 7 дело
проходило с первого раза: нестабильность поведения модели на большом регистре, не дефект шлюза.
Дело `14-save-recipe` в eval не запускалось (оно пишет в дом владельца, а его демон ещё на
утреннем коде без поля `config`); тот же сценарий проверен вручную на пустом доме (таблица выше).

## Не проверено в этой приёмке

- **Двойной вопрос на `odata1c_commit`** (хук `ask` плюс диалог по `_meta`) — только в
  интерактивном Claude Code, `claude -p` диалогов не показывает. Инструкция владельцу: в обычной
  сессии подготовить снятие пометки удаления с элемента с маркером `odata1c-приёмка` и вызвать
  `commit`; ожидание — один вопрос. Два вопроса подряд — снять правило 1 из
  `plugin/hooks/pretooluse.py` (спецификация, раздел 5).
- **Демон владельца** на момент приёмки работает на коде 09:18 (ADR-0015, без библиотеки
  рецептов и версии в `initialize`): `odata1c doctor` в его доме показывает FAIL «версия демона
  неизвестна». Перезапуск — решение владельца (`odata1c daemon stop`, затем переподключение
  `/mcp` в сессиях); после него можно дописать `config: ut` базе `trade_dev`.

## Наблюдения

- Названия складов приходят модели открытыми: `Catalog_Склады` не входит в `names_for` по
  умолчанию (SPEC §6.5, слой 1), и одно из названий содержит часть имени компании. Закрывается
  одной строкой в `policy.yaml` владельца (`names_for`), решение за владельцем.
- Подпись базы (`label` в `bases.yaml`) видна модели по замыслу и попадает в ответы; если в ней
  фамилия, её стоит заменить.
- `claude plugin eval` в Claude Code 2.1.267 — ранний доступ за флагом `CLAUDE_CODE_WALNUT_SPIRE=1`;
  без `--no-publish` отчёт с ответами модели публикуется на claude.ai (один такой отчёт из
  задачи 7 удалён).
- `uv` при первом запуске сервера плагина ставит интерпретатор и пакет сам; повторные запуски
  из кэша — секунды.
