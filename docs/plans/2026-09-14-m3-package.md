# M3 (package) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** шлюз ставится на чистую машину двумя командами (`uv` и плагин Claude Code из
маркетплейса GitHub), пакет `odata1c-gate` на PyPI, плагин с навыками, хуком, агентом и evals,
`doctor`, библиотека рецептов по конфигурациям, документация для внешнего читателя, CI на
Windows и Ubuntu, выпуск `0.1.0`, ветка слита в `main`.

**Architecture:** тот же пакет `odata1c` (демон, лаунчер, CLI) получает две новые команды
(`doctor`, `recipe check|list`) и слой библиотеки рецептов; плагин Claude Code — каталог `plugin/`
с манифестом, `.mcp.json` (`uvx --from odata1c-gate==<версия> odata1c mcp`), двумя новыми
навыками, хуком `PreToolUse` на стандартной библиотеке Python и агентом-следователем;
маркетплейс — `.claude-plugin/marketplace.json` в корне репозитория. Версия одна на всё,
источник — `src/odata1c/__about__.py`.

**Tech Stack:** Python ≥ 3.12, `uv`, `hatchling`, `mcp` ≥ 2.2, `pydantic`, `pyyaml`,
`ruamel.yaml`; Claude Code 2.1.267 (плагины, `claude plugin validate|eval`); GitHub Actions;
PyPI trusted publishing.

**Spec:** `docs/superpowers/specs/2026-09-14-m3-package-design.md` (разделы 1–14; нумерация
задач ниже соответствует разделу 12). Первичные документы: `SPEC.md` §3.5, §8, §11, §12, §13;
`AGENTS.md`; `CONTEXT.md`.

## Global Constraints

- Python ≥ 3.12, `requires-python = ">=3.12"`; SDK `mcp>=2.2`; `ruff` `line-length = 100`,
  `select = ["E", "F", "I", "UP", "B", "SIM"]`; `pytest` с `filterwarnings = ["error"]`.
- Инвариант 1 `AGENTS.md`: реальные значения защищаемых классов не выходят через MCP никогда;
  в отчётах, тестах и документации — только формы (цифра → 9, буква → a), никаких значений
  живой базы, адресов серверов и имён пользователей 1С из окружения владельца.
- Пароль базы `trade_dev` только в рабочем `~/.claude/odata1c/bases.yaml`; скрипты читают его из
  файла, никогда литералом; в репозиторий, отчёты и логи не попадает. `gate_secret` из
  `daemon.yaml` не печатать нигде.
- Язык документов, комментариев, коммитов — русский; термины по `CONTEXT.md`, запрещённые
  синонимы не использовать; гибриды «англ. корень + рус. окончание» запрещены.
- Имя дистрибутива `odata1c-gate`; пакет Python и команда — `odata1c`; версия только в
  `src/odata1c/__about__.py`, остальные места повторяют её и проверяются тестом.
- Плагин только для Claude Code; хук — один скрипт на стандартной библиотеке без импортов вне
  неё; имена тулов в обеих формах: `mcp__plugin_odata1c_gate__odata1c_<тул>` и
  `mcp__odata1c__odata1c_<тул>`.
- Linux проверяется только в GitHub Actions; на машине владельца Linux не запускается.
- Демон владельца (порт 7171) исполнители не останавливают и не перезапускают; рабочий дом
  `~/.claude/odata1c/` исполнители не трогают (задачи 1–10). Задачу 11 выполняет контроллер.
- Коммиты: `git commit -F` с трейлером `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`;
  исполнитель работает в своём worktree, в `m0-probes` переносит контроллер.
- Проверка перед каждым коммитом: `uv run ruff check . && uv run ruff format --check . &&
